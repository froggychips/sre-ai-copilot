  ⚠️  WARNING: секреты идут ЧЕРЕЗ VALUES (secrets.existingSecret не задан).

  Значения из values попадают в helm release Secret
  (sh.helm.release.v1.{{ .Release.Name }}.vN) и хранятся там по версиям релиза:
  ротация ключа не убирает его из истории. `--set secrets.*=...` дополнительно
  светит значение в shell history и в argv (виден в `ps`). Это допустимо для
  kind/minikube и НЕ допустимо для prod.

  Как перейти на безопасный путь:

    1. создать Secret вне чарта (SealedSecrets / ExternalSecrets —
       см. k8s/base/secrets.sealed.yaml.example, secrets.external.yaml.example);
    2. helm upgrade ... --set secrets.existingSecret=<name>
       и убрать значения из values-файлов;
    3. проверить, что поды перечитали env: kubectl -n {{ .Release.Namespace }} rollout restart \
         deploy/{{ include "sre-ai-copilot.fullname" . }}-api \
         deploy/{{ include "sre-ai-copilot.fullname" . }}-worker \
         deploy/{{ include "sre-ai-copilot.fullname" . }}-beat
